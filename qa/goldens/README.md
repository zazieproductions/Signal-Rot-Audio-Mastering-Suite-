# Protected sonic baselines

Known-good renders, with the numbers an independent meter sees. A future build is checked against
these the same way the DSP goldens are: render the same fixture, compare. The point is not to lock in
perfection — it is to make a regression _visible_ instead of arguable.

    QA_MAT=/path/to/materials node qa/scripts/render.mjs --jobs qa/jobs-smoke.json --out /tmp/chk
    python3 qa/scripts/audit.py --dir /tmp/chk
    node tools/audio-regression/compare.js --baseline ... --candidate ...   # repo's own comparator

## Baseline: `17b77c7` — v7.0.0, `mastering` family, measured in this sandbox

Fixtures are generated by `qa/scripts/gen_materials.py` (deterministic, seeded). `Reference HD` at its
own −15 LUFS target, ceiling −1 dBTP, 24-bit output. `LUFS`/`TP` below are from `qa/scripts/measure.py`
(BS.1770-4 gated, exact band-limited true peak), not from the engine's own meters.

| fixture            | LUFS   | TP dBTP  | crest | corr  | mono fold | attack Δ | note                                                             |
| ------------------ | ------ | -------- | ----- | ----- | --------- | -------- | ---------------------------------------------------------------- |
| acoustic (dynamic) | −15.01 | −0.70 ⚠ | 17.1  | +0.92 | −3.2 dB   | +0.4     | clean, open, but the tilt of SON-4 is present                    |
| rock (dense)       | −15.07 | −2.11    | 14.3  | +0.18 | −6.4 dB   | 0.0      | no limiting needed; −7.4 dB HF at matched level                  |

## Also baseline-worthy (behaviour that should not regress)

- **Transparency of the assembled graph at defaults, stereo material:** 0.01–0.02 dB level change,
  sweep flat to ±0.16 dB from 30 Hz to 12 kHz (`qa/results/evidence/transparency.md`).
- **Loudness accuracy:** median |Δ| = 0.00 LU across 144 preset renders, p90 = 0.22 LU.
- **Loudness restraint:** 0 of 144 preset renders produced a sample above full scale; 12 refused their
  target via the crest-aware cap and 13 via the ambition guard, and said so in the report.
- **Source-awareness is real and directionally right:** `air +12 → +0.5 dB (source already bright)`,
  `tilt +6 → 0 dB`, `input drive 4 → 0 dB (already at mastering loudness)`,
  `mbLow 12 → 5`, `mono-below 0 → 90 Hz (bass-heavy source)`.
- **Dither:** 16-bit undithered shows a −15 dB quantisation spur at the 3rd harmonic of a −48 dBFS
  tone; TPDF moves it to −47 dB and lifts the HF floor ~9.5 dB; the shaped mode tilts that floor
  toward Nyquist (−21.5 vs −23.9 dBFS in 8–14 kHz) exactly as documented. 32-bit float: refused, as
  documented.
- **Determinism:** two renders of the same project + seed are byte-identical (md5 match), including
  the 16-bit dithered path.
- **Immersive bed:** fronts carry the stereo pair unchanged (correlation +1.000 at 0 samples),
  every height feed decorrelated (0 of 15 height pairs bit-identical, L/R pairs symmetric to 0.0 dB),
  LFE low-passed with no top-end content (−210 dB above 10 kHz), bed total +0.4 LU over the stereo
  master.

## Do not promote

`17b77c7` should **not** be treated as a protected _sonic_ baseline for the clean path while SON-1
(mono corruption), SON-3 (resonant crossover) and SON-2 (ceiling) are open. The table above is a
regression tripwire, not a stamp of approval: the numbers worth matching are transparency, loudness
accuracy, restraint, dither and determinism; the numbers that must **change** are the tilt, the
side-channel balance and the true peak.
