# Golden audio regression bank

Every DSP change should be able to answer: _what did this do to the audio, in
numbers?_ This bank is the input to that answer.

```bash
npm run lab:goldens     # synthesise fixtures, measure, write JSON
npm run lab:compare     # baseline JSON vs candidate JSON → report
npm run lab:bench       # Node-side analysis / limiter timing
```

No copyrighted audio is stored. Fixtures are generated by
`tests/fixtures/generate.js` from seeded math.

## Fixtures

| id                         | What it is                             |
| -------------------------- | -------------------------------------- |
| `impulse`                  | Unit impulse                           |
| `sine-sweep`               | 20 Hz–20 kHz log chirp                 |
| `multitone`                | Seven inharmonic sines                 |
| `bass-40` … `bass-100`     | 40 / 50 / 60 / 80 / 100 Hz sines       |
| `transient-train`          | Sharp hits on a quiet bed              |
| `clipped-source`           | Already-squared sine                   |
| `pink-noise`               | Voss-McCartney −3 dB/octave            |
| `correlated-stereo`        | Dual-mono, r = +1                      |
| `anti-correlated-stereo`   | Polarity invert, r = −1                |
| `hard-left` / `hard-right` | One-channel energy                     |
| `wide-diffuse`             | Decorrelated synthetic ambience        |
| `bright-synthetic`         | HF cluster                             |
| `dense-compressed`         | Low-crest programme surrogate          |
| `highly-dynamic`           | 18 dB two-level programme + transients |

Each measurement records:

- integrated loudness (BS.1770-4, same code as the product)
- sample peak and true peak
- RMS (sine-referenced) and crest factor
- correlation and per-band mono loss
- M/S energy
- spectral centroid and six-band summary
- DC, NaN/Infinity audit, per-channel energy

JSON snapshots live in `tests/fixtures/goldens/`.

## REFERENCE vs CREATIVE

The comparer refuses to fail a creative preset because it changed the audio.
Classification is a property of the **parameter set**
(`tests/conformance/classify.js`):

- **REFERENCE / CLEAN** — schema defaults, plus delivery controls (normalise,
  target, ceiling, dither). Unexplained > 1 dB loudness jumps, crest collapse,
  spectral tilt, correlation collapse, extra mono loss are **defects**.
- **CREATIVE / SIGNAL ROT** — any colour, width, saturation, glue, tape, depth.
  The same deltas are **notes**. NaN, Infinity, unexpected DC, true-peak
  violations and missing immersive channels are still defects.

## Comparing commits without touching Agent A's tree

Do **not** check out another branch in this worktree. Read committed goldens
with `git show`:

```bash
node tools/audio-regression/compare.js \
  --baseline tests/fixtures/goldens/sources.v1.json \
  --baseline-ref origin/main \
  --candidate tests/fixtures/goldens/sources.v1.json \
  --candidate-ref WORKTREE \
  --out lab-results/regression
```

Add `--browsers lab-results/conformance` to fold in cross-engine captures.

Exit code 1 only when a _defect_ flag is raised.

## Flags

| kind                                               | REFERENCE | CREATIVE |
| -------------------------------------------------- | --------- | -------- |
| `loudness-change` > 1 LU                           | defect    | info     |
| `true-peak-violation`                              | defect    | defect   |
| `crest-collapse`                                   | defect    | info     |
| `spectral-shift`                                   | defect    | info     |
| `mono-sum-degradation`                             | defect    | info     |
| `correlation-collapse`                             | defect    | info     |
| `dc` > 0.05 FS (or +0.02 vs baseline on reference) | defect    | defect   |
| `nan` / `infinity`                                 | defect    | defect   |
| `missing-immersive-channels`                       | defect    | defect   |
| `silent-feed`                                      | defect    | defect   |
| `browser-divergence`                               | note      | note     |

## Immersive fixtures

`tests/conformance/immersive-catalog.js` snapshots every layout (5.1, 7.1,
7.1.2, 7.1.4, 9.1.6, Sonic Lab 20.4): channel order, mask, LFE indices, ADM /
HRTF azimuths, and a front/rear/left/right/height/sub role for each feed.

The Playwright suite then _renders_ those feeds and checks energy, silence and
L/R placement. Visual / numerical spatial-energy summaries are in
`lab-results/conformance/<browser>/immersive.json`.

## Performance

Two benches, neither of which patches production code:

- **Node** (`npm run lab:bench`) — loudness, true-peak, limiter vs channel count.
- **Browser** (`tests/browser/benchmark.spec.js`) — `OfflineAudioContext` render
  time for stereo / 7.1.4 / 9.1.6 / Sonic Lab 20.4 at 44.1 / 48 / 96 / 192 kHz
  where the engine allows it.
